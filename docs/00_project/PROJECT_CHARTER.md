## 1. 프로젝트명

- 코드명: `BREAK NOTICE`
- 장르: 3D 3인칭 물리 액션 Roguelite
- 개발 형태: 1인 개발
- 엔진: Unity 6
- G1 기준 플랫폼: `Windows PC`
- 모바일 동시 출시: `OUT / WON'T`

- 정확한 하드웨어, 해상도와 성능 기준: `G3/G6 DRAFT`
- 개발 방식: 폭포수 모델 + Graybox 검증 게이트

## 2. 문제 정의

일반적인 사무실 액션 게임은 총기나 초능력에 의존하며, 주변 사물이 실질적인 전투 시스템이 아니라 장식에 머무르는 경우가 많다. 본 프로젝트는 평범한 사무용품, 동료의 전달 행동, 실제 궤적과 충돌 결과를 중심으로 전투를 구성한다.

## 3. 제품 비전

BREAK NOTICE는 해고 통보를 받은 사내 자산관리 직원이 산업용
화물 장비와 동료의 물리적 릴레이로 사무용품을 직접 받아 던지고
방향을 바꾸며, 읽을 수 있는 연쇄 충돌로 사무실의 국소 상태를
재구성하는 3인칭 물리 액션 게임이다.

### Target Player

읽기 쉬운 물리 액션 실험과 3인칭 액션을 즐기며,
설계된 방을 반복 플레이해 다른 물체·각도·순서의 인과 결과를
발견하려는 플레이어. Roguelite 경험은 도움이 되지만
필수 전제는 아니다.

## 4. 핵심 성공 조건

### Owner-Approved G1 Qualitative Intent

짧은 첫 플레이에서 플레이어는 직접 획득, 동료의 물리적 릴레이와
화물 스트랩 리디렉션이 실제 경로와 기계적 연결로 작동함을
이해하고, 이해 가능한 국소 room-state change를 만든 뒤
다른 물체·각도·순서를 자발적으로 시험하거나 Reset하며,
이를 염력이 아닌 물리적 팀워크로 설명할 수 있어야 한다.

### G4/G5/G6 DRAFT CANDIDATE METRICS — NOT G1-APPROVED VALUES

- 플레이어가 60초 안에 첫 만족스러운 연쇄 충돌을 만든다.
- 설명 없이도 동료 패스와 물체 리디렉션의 인과를 이해한다.
- 같은 방을 세 번 플레이했을 때 서로 다른 결과가 나온다.
- 5분 테스트 후 60% 이상의 플레이어가 자발적으로 Reset한다.
- 실제 플레이 화면이 “염력”이 아니라 “물류 장비와 팀워크”로 읽힌다.
- 1인 개발자가 유지·디버깅·확장 가능한 구조를 유지한다.

## 5. 제약 조건

- 핵심 개발자 1명
- Codex를 주요 구현 보조 도구로 사용
- 네트워크 멀티플레이 제외
- 실시간 완전 파괴 제외
- 포토리얼 AAA 품질 제외
- 일반 전투 동료 1명
- 버티컬 슬라이스 전까지 콘텐츠 확장 금지

## 6. 제품 원칙

1. Fun first, but every feature must be specifiable and testable.
2. 물체는 순간이동하지 않는다.
3. 충돌은 위치·자세·공간 중 최소 하나를 바꾼다.
4. 동료는 플레이어를 대체하지 않는다.
5. 파괴는 큰 조각과 명확한 결과를 우선한다.
6. 캐릭터는 진지하고, 물리 결과가 코미디를 만든다.
7. 구현량이 아니라 통합·검증 가능성을 기준으로 범위를 정한다.

## 7. 승인 권한

1인 프로젝트이므로 제품 책임자, 설계 책임자, 기술 책임자, QA 승인자는 개발자 본인이다. 단, 역할을 분리하여 문서와 게이트를 생략하지 않는다.
