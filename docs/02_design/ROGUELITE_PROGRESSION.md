# Roguelite Progression

## 원칙

- 업그레이드는 가능한 행동을 바꾼다.
- 영구 공격력 숫자 누적은 최소화한다.
- 빌드는 Light 정밀, Rolling Medium, Structural Heavy, Catch 반격으로 구분한다.

## 선택 흐름

- 방 클리어 후 3개 제시
- 동일 계열만 강요하지 않도록 최소 2계열 포함
- 텍스트보다 변화할 행동을 미리 보여주는 짧은 아이콘/클립 사용

## 제외

- 장비 희귀도 인벤토리
- 랜덤 공격력 5~10%
- 영구 스탯 그라인드
- 런 외 복잡한 화폐 경제
