## G1 Qualitative Intent

짧은 첫 플레이에서 플레이어는 직접 획득, 동료의 물리적 릴레이와
화물 스트랩 리디렉션이 실제 경로와 기계적 연결로 작동함을
이해하고, 이해 가능한 국소 room-state change를 만든 뒤
다른 물체·각도·순서를 자발적으로 시험하거나 Reset하며,
이를 염력이 아닌 물리적 팀워크로 설명할 수 있어야 한다.

## Current G4-A authority

- Protocol:
  `docs/07_quality/G4A_DETAILED_EVIDENCE_PROTOCOL.md`
- Status: `OWNER-APPROVED / READY FOR FUTURE EXECUTION AUTHORIZATION`
- Scored Binary Round: 참가자 `3`명 × 시도 `2`회 = 총 `6`회
- Optional Exploratory Round: non-scoring session 정확히 `2`개
- Binary Retest: bounded Retune 뒤 최대 `1`회
- Q2-only Layout Recheck: PASS rule 충족·Q2 NO일 때 layout-only 최대 `1`회
- Mandatory questions: `Q1`, `Q3`, `Q5`
- Evidence: `NOT COLLECTED`
- Execution: `NOT STARTED / NOT AUTHORIZED`

이 요약이 프로토콜과 충돌하면 프로토콜이 우선한다. 여기에는 Build,
participant session, evidence collection 또는 G4 passage 권한이 없다.
