# Playtest Plan

## 대상

첫 외부 테스트 20명 권장. 물리 액션 경험자와 비경험자를 섞는다.

## 설명 정책

- 조작 최소 안내만 제공
- Chain 정답을 설명하지 않음
- 동료 패스를 발견하는 행동 관찰

## 핵심 지표

| 지표 | 합격 기준 |
|---|---:|
| 보이는 물체 Scoop 성공률 | 95% 이상 |
| 첫 만족스러운 Chain | 60초 이내 |
| 투척 손맛 5점 평균 | 4.0 이상 |
| 자발적 Reset | 60% 이상 |
| 5분 서로 다른 Chain | 중앙값 3회 이상 |
| Chain 원인 설명 가능 | 80% 이상 |
| 카메라로 목표 상실 | 10% 미만 |
| 물리 버그를 재미보다 먼저 언급 | 20% 미만 |
| 다른 물체를 시험하고 싶음 | 70% 이상 |

## 관찰 질문

- 직접 집기와 동료 패스를 번갈아 쓰는가?
- 동료가 던지는 순간 시선이 가는가?
- 패스 후 즉시 투척이 자연스러운가?
- 스트랩을 염력으로 오해하는가?
- Heavy를 처음 5분 안에 경험하는가?

## 판단

설문보다 자발적 행동을 우선한다. 테스트 종료 후 Reset을 직접 누르는지 기록한다.
