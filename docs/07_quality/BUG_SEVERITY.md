# Bug Severity

| 등급 | 정의 | 예시 |
|---|---|---|
| S0 Blocker | 실행·저장·진행 불가, 데이터 손상 | 빌드 실행 불가, 무한 크래시 |
| S1 Critical | 핵심 루프 불가 또는 심한 안전 실패 | 물체 대부분 관통, Reset 누수, Chain 무한 폭주 |
| S2 Major | 주요 기능 오작동·가독성 손상 | Catch 반복 실패, 동료 끼임, 카메라 가림 |
| S3 Minor | 대안이 있는 오류 | 작은 VFX 위치, 일시적 애니메이션 튐 |
| S4 Cosmetic | 플레이 영향 거의 없음 | 경미한 텍스처·문구 |

G4/G6 Gate에서는 S0, S1이 0개여야 하며, MUST 기능 관련 S2도 0개여야 한다.
