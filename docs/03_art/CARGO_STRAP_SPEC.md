# Cargo Strapping System — Visual and Functional Spec

## 구성

1. 허리 장착형 수축 릴
2. 검정·황색 직조 화물 스트랩
3. 은색 카라비너
4. 교체 가능한 자산 고정 클립
5. 브레이스 장력 잠금 레버
6. 기계적 장력·하중 표시

## 기능

- 연결 가능 표면: 손잡이, 금속 프레임, 지정 Anchor
- 최대 거리는 짧고 화면 내에서 이해 가능해야 함
- 움직이거나 굴러오는 Medium의 방향 보정
- 흔들리는 가구 전도 보조
- 과도한 장력에서 자동 해제

## 시각 언어

- 스트랩은 항상 릴에서 물체까지 연속적으로 보여야 한다.
- 카라비너가 물체의 고정점에 실제 접촉해야 한다.
- 장력은 스트랩 직선, 몸의 기울기, 브레이스 자세로 표현한다.
- 기계 표시등은 작은 황색으로 제한한다.

## 금지

- 넥타이 연결
- 목에서 줄이 나옴
- 공중 물체 소환
- 그래플링 이동
- 에너지 케이블
- Heavy 원거리 견인
- 무한 거리·장애물 관통
