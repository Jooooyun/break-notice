# ADR-0009: CHR_01 First Ally Identity Production Visual Lock v001

- Status: Accepted
- Date: 2026-07-17

## Decision

`references/approved/characters/CHR_01_First_Ally_Identity_v001_FINAL.png`를 CHR_01 First Ally Identity Production Visual Canon으로 승인한다.

## Canon

- 평범하고 현실적인 시설·물류 직원 정체성
- 회청색 계열의 실용 작업복
- 회사 사원증, 작업 장갑, 안전화와 소형 유지보수 파우치
- 현실적인 현장 근무자 체형과 절제되고 진지한 표정
- CHR_00의 넥타이·브레이스·하네스·허리 릴·화물 스트랩을 복제하지 않는 실루엣
- 보안·군사·전술·슈퍼히어로 장비와 구분되는 일반 직원 실루엣

세부 Canonical Elements는 `docs/03_art/ALLY_VISUAL_SPEC.md`를 따른다.

## Non-Canon

- 정확한 얼굴 세부, 성별 표현, 민족성, 정확한 나이와 머리 모양
- 이름, 성격과 개인 배경 이야기
- 피부·머리카락 렌더 품질, 주름·마모·흠집 위치와 미세 비대칭
- `Facilities Mover` 영문 역할명
- 패스 재고·거리·타이밍, Relay Position, Suppressed, Heavy 지원, AI, 애니메이션 수
- 리깅, IK와 Unity 구현

## Consequences

- CHR_01은 `LOCKED` Production Visual이다.
- 다음 Production Visual 대상은 `PGT_01 — Gameplay Camera`다.
- Implementation Gate는 `CLOSED`로 유지한다.
