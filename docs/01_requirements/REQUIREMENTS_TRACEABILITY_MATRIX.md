## Status Vocabulary

| 축 | 허용 값 |
|---|---|
| 적용 단계 | `PROTOTYPE CORE`, `VERTICAL SLICE`, `P2`, `OUT` |
| Priority | `MUST`, `SHOULD`, `COULD`, `WON'T` |
| Authority | `DRAFT`, `OWNER-APPROVED`, `DEFERRED`, `REJECTED`, `SUPERSEDED` |
| Trace | `UNMAPPED`, `PARTIAL`, `MAPPED`, `VERIFIED` |

`OWNER-APPROVED`는 Owner가 항목의 정확한 기준선 문구와
disposition을 승인했다는 뜻이며 구현, 테스트 통과, 기술 설계,
후속 milestone 편입, G1·G2 통과 또는 Gate 개방을 뜻하지 않는다.
아래 Authority 값은 Owner-approved G1 mapping을 반영한다.

`MAPPED`는 현재 단계의 Requirement, Authority, Design, Technical
intent와 Validation intent가 의미 있게 연결되었다는 뜻이며 승인이나
검증 완료를 의미하지 않는다. 후속 기술·검증·범위 결정이 필요한
행은 `PARTIAL`로 유지한다. 이 G1 RTM에는 `VERIFIED` 항목이
없다.
