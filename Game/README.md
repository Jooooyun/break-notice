# Unity Project Placeholder

이 폴더는 Unity 6 프로젝트가 생성될 위치다. 현재는 설계 동결 전이므로 실제 Unity 메타·패키지·ProjectSettings를 임의로 생성하지 않는다.

Bootstrap 작업에서 다음을 수행한다.

1. 정확한 Unity 6 Editor patch 선택
2. URP 템플릿 생성
3. Input System, Cinemachine, AI Navigation 등 승인 패키지 버전 잠금
4. `Assets/_Project` 구조 적용
5. asmdef와 테스트 구조 생성
6. 첫 Prototype scene 생성

Bootstrap은 별도 승인된 Codex TASK로 수행한다.
