# 다리 길이(본 비율) 불일치 — 해결 방향

`updatedAnimation/`의 새 클립(Jab Cross, Pickup Medium/Small 등)을 Generic으로 기존 프로젝트 모델에 붙였을 때 다리 길이가 안 맞는다고 보고받음. 원인과 선택지 정리.

## 원인
`updatedAnimation/` 안의 fbx 37개는 전부 **같은 WIP.blend, 같은 Armature**에서 뽑음 — 서로간에는 본 비율이 100% 동일함이 보장됨. 문제는 그게 아니라, 지금 프로젝트에 이미 들어가있는 "기존 모델"이 이 리그와 본 비율이 다르다는 것. Generic 타입은 뼈의 위치/회전 좌표를 그대로 복사하기 때문에, 비율이 다른 스켈레톤 사이에서는 다리가 늘어나거나 짧아지는 식으로 깨짐.

## 선택지 A — 모델 자체를 통째로 교체 (권장)
`updatedAnimation/` 안 fbx 아무거나 하나(예: `CHR00_Idle.fbx`)를 프로젝트의 정식 캐릭터 모델로 교체. 그 이후로 붙이는 모든 클립이 같은 리그에서 나온 거라 리타겟팅이나 비율 문제 자체가 사라짐. Generic으로 그냥 갖다 붙이면 됨.

- 장점: 가장 단순하고 안전함, 향후 배포되는 애니메이션도 전부 자동으로 호환
- 단점: 이 fbx들은 **언텍스처드**임(머티리얼만 있고 텍스처 이미지 없음). 기존 모델에 이미 텍스처가 씌워져 있었다면 교체 시 텍스처가 없어짐 — 새로 입히거나 당분간 무텍스처로 진행해야 함

## 선택지 B — 기존 모델 유지, Humanoid로 리타겟
기존 모델을 그대로 쓰고 싶으면(텍스처 때문에), 각 클립 fbx를 개별적으로 **"Create Avatar From This Model"**로 Humanoid Avatar 생성 → 거기서 나온 Humanoid AnimationClip만 뽑아서 기존 모델의 Avatar로 리타겟. Humanoid는 근육(muscle) 정규화 공간을 쓰기 때문에 본 비율이 달라도 자동 보정됨.

- 주의: 절대 파일 간 **"Copy From Other Avatar"**로 맞추려 하지 말 것 — 이번 작업 중 실제로 뼈 길이 미스매치 Rig Error 재현됨. 각 fbx는 자기 자신한테서 독립적으로 Avatar를 생성해야 그 에러가 안 남(이미 스킨+본 통째로 포함돼있어서 가능함)
- 장점: 기존 모델(텍스처 포함) 그대로 유지 가능
- 단점: 클립마다 매번 이 과정 반복해야 함, Small 캐치/그립처럼 정밀한 손 위치가 필요한 애니메이션은 근육 정규화 과정에서 손 위치가 미묘하게 어긋날 수 있음(체크 필요)

## 결정 기준
기존 모델에 텍스처가 이미 있고 그게 중요하면 → **B**
텍스처 없거나 상관없으면 → **A** (더 단순하고 이후 작업이 편함)

무엇을 선택하든 Idle 하나로 먼저 검증한 뒤 전체 적용하는 접근은 맞음.
