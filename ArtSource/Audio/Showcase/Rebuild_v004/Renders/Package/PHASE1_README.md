# WP02 Phase 1 — T3 blind

1. 고정된 노트북 볼륨으로 X와 Y MP4를 각각 재생한다. 두 영상 스트림은
   동일하고 소리만 다르다. MP4가 안 열릴 때만 같은 X/Y 라벨의 WAV를 사용한다.
2. 각 pair는 두 variation을 담고 있으며 둘 다 -20.0 LUFS로 review-match됐다.
3. 노트북 선택을 먼저 기록한 뒤 같은 X/Y를 헤드폰에서 재검사하고 헤드폰
   선택도 별도로 기록한다. 둘이 다르면 이유를 남긴 뒤 최종 X/Y 하나를 잠근다.
4. `LISTENING_RESPONSE_TEMPLATE.md`의 Phase 1을 완성한다.
5. 이 답을 Owner에게 보내기 전에는 Phase 2·3을 받거나 매핑을 요청하지 않는다.

이 단계에는 신규 RC 개별본, ladder, cue hash, 정답이 의도적으로 없다.
