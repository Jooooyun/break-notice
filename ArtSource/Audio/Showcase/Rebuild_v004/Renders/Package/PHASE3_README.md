# WP02 Phase 3 — deblind, detail, evidence

이 ZIP은 Phase 1 X/Y 선택과 Phase 2의 20개 답이 Owner에게 제출된 뒤에만 연다.

1. `Private/`의 키로 tier/material 점수와 T3 매핑을 확인한다.
2. actual-dynamic ladder WAV/MP4와 T1 stress를 노트북에서 검수한다.
3. 같은 항목과 T3 X/Y를 헤드폰에서 재검수한다.
4. 11개 composite를 spot-check하고 필요한 경우 55개 stem을 solo한다.
5. `Docs/REVIEW_CHECKLIST.md`와 `LISTENING_RESPONSE_TEMPLATE.md`를 완성해
   `PASS LADDER`, `PASS WITH NOTES`, `REJECT LADDER` 중 하나를 권고한다.

`Evidence/*.json`의 파일 경로는 제작 트리 기준이다. ZIP 안에서는 같은
basename의 파일을 `Listening/` 또는 `T3_Reference/`에서 찾는다.

이 단계의 deblind는 의도적이다. 결과는 REVIEW 판정이며 FINAL 또는 Runtime
연결 권한이 아니다.
