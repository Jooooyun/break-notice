# T3 Phase 1 — pair blind

이 ZIP만 새 폴더에 압축 해제하고, Phase 2·3 ZIP은 아직 열지 마십시오.

1. `T3_PAIR_M_BLIND_REVIEW.mp4`와 `T3_PAIR_N_BLIND_REVIEW.mp4`를 먼저 비교합니다.
2. WAV는 각 MP4와 같은 오디오의 무손실 대체본입니다. MP4 재생이 불안정하거나 세부를 다시 확인할 때만 사용하며 별도 후보로 세지 않습니다.
3. 각 파일은 v01, 650ms 무음, v02 순서입니다. 시스템 음량을 바꾸지 말고 헤드폰에서 각 6회, 노트북 스피커에서 각 6회 반복합니다.
4. 더 무거운 쪽, Chair→Runner→Floor 인과가 읽히는 쪽, 반복 피로가 적은 쪽을 판단합니다.
5. `PHASE1_RESPONSE.md`의 모든 항목을 작성하고 저장한 뒤 그 전문을 현재 Codex 작업에 전송합니다. 전송된 답이 Phase 1 잠금본이며 이후 수정하지 않습니다.
6. Phase 1 답을 전송하기 전에는 Phase 2를 열지 않습니다.

이 단계에서는 정답표, 측정 자료, source·stem 정보를 열지 않습니다.
