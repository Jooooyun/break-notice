# T3 Phase 2 — variation blind

Phase 1 잠금본을 현재 Codex 작업에 전송한 뒤에만 이 ZIP을 새 폴더에 압축 해제하십시오. Phase 3은 아직 열지 마십시오.

1. v01의 A/B와 v02의 P/Q를 서로 독립적으로 판정합니다. MP4를 먼저 사용하고, WAV는 같은 오디오의 무손실 대체본으로만 사용합니다.
2. 시스템 음량을 바꾸지 말고 각 비교를 헤드폰 6회, 노트북 스피커 6회 반복합니다.
3. 무게, Chair 재질, Runner body, Floor settle, 반복 피로를 기준으로 각 variation을 따로 고릅니다.
4. `PHASE2_RESPONSE.md`의 모든 항목을 작성하고 저장한 뒤 그 전문을 현재 Codex 작업에 전송합니다. 전송된 답이 Phase 2 잠금본이며 이후 수정하지 않습니다.
5. 두 답을 전송하기 전에는 Phase 3을 열지 않습니다. 어느 한 variation이라도 실패하면 T3 전체는 PASS가 아닙니다.
